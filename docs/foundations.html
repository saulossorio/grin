Três camadas de tokens

CamadaArquivoO que guardaQuem usa
Coretokens/core/*.jsonValores brutos: escalas de cor de 12 passos, espaços, raios, sombras, tipos, durações.Só os tokens semânticos.
Semânticatokens/semantic/colors.jsonO papel de cada cor: primary, muted-foreground, crit-fg. Valores do tema claro.Todos os componentes.
Temastokens/themes/*.jsonTrocam só os valores dos tokens semânticos: escuro e alto contraste.O atributo data-theme.
/* certo: o componente diz o papel da cor e funciona nos três temas */
.badge.crit { color: var(--crit-fg); background: var(--crit-bg); }

/* errado: cor escrita direto, quebra no tema escuro */
.badge.crit { color: #b02b27; background: #fef6f4; }
