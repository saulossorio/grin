Fundamentos

Como os tokens se organizam, como funcionam os temas e a densidade, e o que foi decidido onde Canis, Laika e Vezen eram diferentes.

Três camadas de tokens

Os arquivos em tokens/ são a fonte de verdade. styles/variables.css é gerado a partir deles por node tools/build-tokens.mjs e nunca se edita à mão.

CamadaArquivoO que guardaQuem usa
Coretokens/core/*.jsonValores brutos: color.brand.green-400 = #8dc63f, space.4 = 16 px, font.size.base = 0,875 rem.Só os tokens semânticos.
Semânticatokens/semantic/colors.jsonO significado: primary, crit-fg, border-strong. Os valores são os do tema claro.Todos os componentes. Nenhum componente usa cor escrita direto.
Temastokens/themes/*.jsonTroca só os valores dos tokens semânticos: escuro e alto contraste.O atributo data-theme na raiz.
/* certo: o componente diz o que a cor significa */
.badge.t-crit { color: var(--crit-fg); background: var(--crit-bg); }

/* errado: cor escrita direto, quebra no tema escuro */
.badge.t-crit { color: #b91c1c; background: #fef2f2; }

Temas

Quatro escolhas para a pessoa: seguir o sistema (padrão), claro, escuro e alto contraste. Seguir o sistema significa não pôr atributo nenhum; o CSS lê prefers-color-scheme e prefers-contrast.

TemaAtributoFundoTextoRegra de contraste
Clarodata-theme="light"#ffffff#1e2324Texto 4,5:1, interface 3:1
Escurodata-theme="dark"#1e2324#e8eceaTexto 4,5:1, interface 3:1
Alto contrastedata-theme="hc"#ffffff#000000Texto 7:1, bordas pretas, foco de 3 px

O alto contraste é novo: nenhuma das três ferramentas tinha. Ele entra sozinho quando o sistema operacional pede mais contraste.

A cor da marca

O verde da 4Network, #8dc63f, foi conferido na folha de estilo de 4network.com. Sobre branco ele dá 2,04:1, abaixo dos 3:1 exigidos para um elemento de interface e dos 4,5:1 para texto. Por isso ele aparece de três jeitos:

UsoTokenClaroEscuro
Preenchimento, com texto escuro em cima--primary#8dc63f com #1e2324 (7,8:1)igual
Texto e link de marca--link, --brand-fg#4d7c0f (5,0:1)#8dc63f (7,8:1)
Ícone, contorno e foco--ring#5c8f22 (3,9:1)#8dc63f (7,8:1)

Faça

Use o verde em áreas pequenas: barra de 6 px no topo, item de menu ativo, chip de filtro ativo, botão primário, anel de foco, triângulo de célula editada.

Não faça

Não pinte fundos de tela, cabeçalhos de tabela ou cartões inteiros de verde, e não use verde para dizer "deu certo": sucesso é azul petróleo (--ok-fg).

Densidade e tamanho da fonte

Duas densidades, escolhidas pela ferramenta e trocáveis pela pessoa. A fonte tem três tamanhos (100%, 112,5% e 125%); como tudo é medido em rem, a interface inteira cresce junto.

DensidadeAtributoBotão e campoTexto dos controlesPara
Compacta (padrão)nenhum32 px13 pxTrabalhar horas numa tabela: Canis e Laika
Confortáveldata-density="comfortable"40 px15 pxLer e analisar: Vezen
