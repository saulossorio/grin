Instalar

<link rel="stylesheet" href="styles/fonts.css">       <!-- Geist e Geist Mono -->
<link rel="stylesheet" href="styles/variables.css">   <!-- tokens (gerado) -->
<link rel="stylesheet" href="styles/global.css">      <!-- base e utilitários -->
<link rel="stylesheet" href="styles/components.css">  <!-- todos os componentes -->
<script type="module" src="scripts/theme.js"></script>

Tema

AtributoEfeito
nenhumSegue o sistema: prefers-color-scheme e prefers-contrast.
data-theme="light"Claro.
data-theme="dark"Escuro.
data-contrast="more"Alto contraste, no claro ou no escuro: texto a 7:1, bordas fortes, foco de 3 px. "normal" desliga mesmo se o sistema pedir mais contraste.

Densidade e tamanho da fonte

AtributoEfeitoControle
nenhumDensidade confortável: controles de 44 px, texto de 16 px.<input type="radio" data-set-density value="compact|comfortable">
data-density="compact"Controles de 36 px, texto de 14 px.
data-scale="112" ou "125"Fonte em 112,5% ou 125%. Tudo é medido em rem e cresce junto.<input type="radio" data-set-scale value="100|112|125">

Estrutura do repositório

index.html              visão geral
docs/                   guias: getting-started, foundations, components, patterns, accessibility
examples/               telas completas: dashboard, form, tutorial, landing
tokens/
  core/                 valores brutos: colors.json (escalas de 12 passos), spacing.json, typography.json
  semantic/colors.json  o significado de cada cor; os componentes só usam estes
  themes/               light.json, dark.json, high-contrast.json
styles/
  fonts.css             @font-face de Geist e Geist Mono
  variables.css         todos os tokens em CSS (gerado por tools/build-tokens.mjs)
  global.css            reset, tipografia, foco, utilitários, animações
  components.css        importa o CSS de todos os componentes
  docs.css              só das páginas de documentação
components/<nome>/      <nome>.html (exemplo comentado), <nome>.css e, se precisar, <nome>.js
scripts/                theme.js, utils.js (ícones, contraste), animations.js, docs-shell.js
assets/                 fontes (com a licença OFL) e favicon
tools/                  build-tokens.mjs, check-contrast.mjs

Convenções

  • Código em inglês, textos em português.
  • Classes: .card, .card-header, .btn.primary.
  • Tons: crit, warn, info, ok, brand.
  • Estados por ARIA: aria-current, aria-selected, aria-invalid.
  • Cor só por token semântico.
