Componentes

Cada componente vive em components/nome/, com a estrutura em HTML, o estilo em CSS e, quando precisa, o comportamento em JS. O CSS usa só tokens semânticos. Os exemplos ao vivo estão na visão geral.

Como criar um componente novo

  1. Crie components/nome/ com nome.html (estrutura comentada), nome.css e, se precisar, nome.js.
  2. No CSS, use só tokens semânticos (var(--…)). Se faltar uma cor, crie o token em tokens/semantic/colors.json e nos temas, e rode node tools/build-tokens.mjs.
  3. Acrescente o @import em styles/components.css.
  4. Ponha um exemplo ao vivo em index.html e uma linha neste inventário.
  5. Rode node tools/check-contrast.mjs se mexeu em cores.
